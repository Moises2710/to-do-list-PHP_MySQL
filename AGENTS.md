# AGENTS.md - Developer & Agent Instructions

This document defines the architecture, project structure, tech stack, dependencies, and development conventions for the **To do List** project. Any AI agent or developer contributing to this project must adhere to these guidelines.

---

## 1. Project Overview

- **Project Name**: To do List
- **Architecture**: Monolithic MVC (Model-View-Controller)
- **Description**: A modern, monolithic web application for managing to-do lists, daily tasks, and personal productivity.

---

## 2. Technology Stack & Dependencies

### Backend & Infrastructure
- **Containerization**: Docker & Docker Compose
- **Language & Server**: PHP 8.2 with Apache (`mod_rewrite` enabled)
- **Architecture**: Monolithic MVC
- **Package Manager**: Composer
- **Routing**: `nikic/fast-route` (`^1.3`)
- **Database**: MySQL 8.0 (using PHP `PDO` for secure, parameterized queries)

### Frontend
- **Structure**: HTML5 (Semantic elements)
- **Styling**: Bootstrap 5.3 (via CDN) + Custom CSS (`public/assets/css/style.css`)
- **Icons**: Bootstrap Icons (via CDN)
- **Client Logic & Async**: Vanilla JavaScript (ES6+), `fetch()` API / AJAX for asynchronous operations.

- **MySQL Database**: `localhost:3306` (Database: `todo_list_db`, User: `root`, Password: `root_password`)

### Stop Application
```bash

```

## 5. Architectural Rules & Responsibilities

1. **Front Controller Pattern**:
   - All incoming HTTP requests pass through Apache `mod_rewrite` to `public/index.php`.
   - Direct access to PHP scripts inside `src/` or `routes/` is forbidden.

2. **MVC Component Separation**:
   - **Controllers (`src/Controllers/`)**: Handle HTTP request processing, validate inputs, invoke Model logic, and return View layouts or JSON responses (for AJAX). Controllers must NOT contain raw SQL queries.
   - **Models (`src/Models/`)**: Extend abstract base `App\Models\Model`. All MySQL database calls must use `PDO` with prepared statements (`PDO::prepare`) to prevent SQL Injection.
   - **Views (`src/Views/`)**: Responsible solely for UI rendering. Views must only contain minimal presentation logic (loops, conditionals) and MUST escape output using `htmlspecialchars()` for XSS prevention.

3. **Routing (`routes/web.php`)**:
   - Routes are explicitly declared mapping HTTP methods and endpoints to `[ControllerClass, methodName]`.

4. **AJAX & Async Operations**:
   - Client-side interactions requiring asynchronous processing must be performed using Vanilla JS `fetch()` to dedicated API/Controller endpoints returning JSON headers (`header('Content-Type: application/json')`).

## 6. Coding & Naming Conventions

- **PHP Standards**: Follow PSR-12 code style guidelines.
  - Namespaces: `App\...` mapped to `src/` directory.
  - Classes: `PascalCase` (e.g., `HomeController`, `TaskModel`).
  - Methods & Variables: `camelCase` (e.g., `getTasksByUserId()`, `$pageTitle`).
  - Constants: `UPPER_SNAKE_CASE`.
- **CSS / Styling**:
  - Prefer Bootstrap 5 utility classes for layout.
  - Custom rules in `public/assets/css/style.css` must use `kebab-case` for class names.
- **JavaScript**:
  - Use modern ES6+ syntax (`const`/`let`, arrow functions, `async`/`await` or `fetch().then()`).
